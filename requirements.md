Project should use the next technologies:
Server:
- express js
- litesql
- docker-compose
- type script

Client:
- types script
- bootstrap css or other modern css framework
- dark/ligh 
- react JS
- library for rendering md text

Project description:
It is simple Proof of Concept project, that will be extended in the future.
Main features:
- creating TODO lists
- each task can have a tags, tags can be selected from exiting, or added as a new by typing in selector field (autocompleate with ability to add new items)
- task can be simple or repeated with predefined or custom period (day, week, month, specific dates)
- task can have description as a separeted md text, UI should have md editor
- task can have specific date (for example user can add task to specific date)
- UI should have: today tasks (repeated and for specific date)
- Admin panel with list of users - credential for admin panel should be in .env file
- User can sign-in/sign-up
- UI - adaptive, modern
